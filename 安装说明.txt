归零归零（含晓晓、云希语音）新电脑安装说明
==========================================

本压缩包包含：
1. 一键安装.bat + install.ps1：一键自动安装脚本
2. 01-GuilingGuiling：归零归零软件（含 TSF 钩子组件）
3. 02-NaturalVoiceSAPIAdapter：晓晓、云希语音适配器（开源项目
   gexgd0419/NaturalVoiceSAPIAdapter）

语音说明：晓晓 1.0.9.0（女声）与云希 1.0.4.0（男声）均为微软官方
原始文件（纯本地合成，无需联网）。微软商店新版（晓晓 1.0.10.0、
云希 1.0.5.0）与适配器不兼容，请勿用新版替换。

════════════════════════════
方式一：一键安装（推荐）
════════════════════════════
1. 把整个压缩包解压到没有中文的路径，例如：
   C:\NVSA
   （不要解压到桌面或任何带中文的文件夹，否则语音可能加载失败。）
2. 打开解压出的文件夹，双击“一键安装.bat”。
3. 弹窗询问管理员权限时点“是”。
4. 等待脚本自动完成（复制、注册、写配置、验证晓晓和云希），
   最后会显示“安装完成”并自动启动归零归零。
5. 如果杀毒软件弹出警告，选择“允许/信任”（常见误报）。

一键安装会自动完成以下事情：
- 把语音适配器和晓晓、云希语音模型装到 C:\Program Files\NaturalVoiceSAPIAdapter
- 注册 32 位和 64 位语音组件
- 写入语音配置（本地语音，关闭在线语音）
- 把归零归零软件装到 C:\GuilingGuiling
- 写入晓晓语音的默认配置（若电脑上已有配置则保留）
- 验证晓晓、云希语音可用后启动软件

════════════════════════════
方式二：手动安装
════════════════════════════
一、解压
1. 解压到没有中文的路径，例如 C:\NVSA。
2. 解压后不要再移动、重命名或删除“02-NaturalVoiceSAPIAdapter”文件夹。

二、安装语音适配器
1. 进入 C:\NVSA\02-NaturalVoiceSAPIAdapter，
   右键 Installer.exe → 以管理员身份运行（UAC 弹窗点“是”）。
2. 勾选“启用讲述人自然语音”。
3. “本地语音路径”填写：
   C:\NVSA\02-NaturalVoiceSAPIAdapter\voices
4. 依次点击“安装 32 位”和“安装 64 位”，
   等右侧状态都变成“已安装 (v0.2.9.0)”。
5. 点“关闭”。
6. 验证：开始菜单搜索“文本到语音转换”，语音选择里应出现
   Microsoft Xiaoxiao (Natural) - Chinese (Simplified, China) 和
   Microsoft Yunxi (Natural) - Chinese (Simplified, China)，
   分别点“预览语音”能听到晓晓、云希说话即成功。

三、安装归零归零软件
1. 把 01-GuilingGuiling 文件夹复制到你想放的位置（例如 C:\GuilingGuiling）。
2. 运行一次 归零归零.exe 让它生成配置文件，然后退出。
3. 把 01-GuilingGuiling\settings.xml 复制到：
   C:\Users\你的用户名\AppData\Roaming\GuiLingGuiLing\
   覆盖同名文件（已预选晓晓语音）。
4. 重新双击 归零归零.exe 即可使用。

════════════════════════════
注意事项
════════════════════════════
1. 安装适配器后，不能移动或删除 C:\Program Files\NaturalVoiceSAPIAdapter
   文件夹。想换位置时，先运行 Installer.exe 卸载，移动后再重新安装。
2. 新电脑讲述人里如果已经装了新版晓晓/云希（商店版），不影响本方案；
   但请勿把它们复制进适配器的 voices 目录替换兼容版。
3. 需要 Windows 10 / 11 64 位系统，.NET Framework 4.8 系统自带。
4. 如果某些软件以管理员身份运行，归零归零也需要以管理员身份运行，
   否则读不到那些软件的按键。
